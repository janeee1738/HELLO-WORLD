# Milestone 2 Updates

## Accessibility Fixes

- Added language attributes to all HTML pages to improve screen reader compatibility.
- Added descriptive alt text to images so users with screen readers can understand the images.
- Improved heading structure to create a logical navigation order.
- Updated text and background colors to pass WCAG AA contrast requirements.
- Fixed all errors found during WAVE accessibility testing.

## Gestalt Principles Used

- Proximity: I grouped related information and project cards together using spacing and card layouts so users can easily understand relationships between content.
- Similarity: I used consistent colors, fonts, borders, and design styles across all pages to create a unified visual experience.

## Accessible Contact Information

- Added a contact information section using semantic HTML elements.
- Included clear labels for phone, email, and address information.
- Used accessible links for phone numbers and email addresses.
